# vietcong-web

Procedural Vietcong-style FPS prototype (Three.js / WebGL).

**Not for resale.** Non-commercial fan project. Fully generated content only.

This repository does **not** include, load, or distribute original Vietcong game files (CBF, BES, models, textures, audio, or maps). OpenVietcong is referenced only as a public documentation/spec project for people who already own the game.

## Run
Open `index.html` in a modern browser, or:
```bash
npx serve .
```

## Controls
WASD move | Mouse look | Click shoot | Esc unlock

## Status
Clean-room procedural starter. Singleplayer only at this commit.
